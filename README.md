# Abhishek Dhautre — Portfolio

A responsive, dark editorial-style developer portfolio built with Next.js, TypeScript, CSS, Framer Motion, and Lucide icons.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Confirm each project description accurately reflects the current implementation.
2. Add screenshots from the real apps to `public/` and replace the abstract project panels if desired.
3. Replace the `https://example.com` metadata base URL in `app/layout.tsx` with the deployed domain.
4. Add a PDF resume to `public/` and add a visible Download Resume link if you want to offer it.
5. Verify that the Faculty Expense Tracker repository link points to its actual repository before launch.
6. Run `npm run build` before deploying.

## Deploy

Push to GitHub and import the repository into Vercel. No backend or environment variables are required for this portfolio starter.
